## install-claude-command-template

프로젝트 루트 폴더에서 `.claude/commands/{timestamp}_{description}.md` 자동 생성

- install

```sh
curl https://raw.githubusercontent.com/rimgosu/script/refs/heads/main/install-claude-command-template.sh | bash
```

- usage

```sh
cct <description>
```
